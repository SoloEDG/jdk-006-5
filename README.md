# 雾港来电 · 午夜频率

## 安装

使用 Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## 测试与构建

```sh
npm test        # 纯逻辑 + IndexedDB 存储测试
npm run build   # 类型检查并产出 dist
```

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8086 。可通过 PORT 环境变量修改端口。

## 场景创作区

顶栏「场景创作区」可以在不改代码的情况下扩展调查故事：

- 上传本地录音（wav / mp3 / m4a / ogg 等），自动解码并生成 100 柱波形。
- 逐句配置字幕：说话人、字幕文字、起止时间点（支持在波形上拖拽手柄或直接填秒数）。
- 每句可挂一个声音线索窗口，线索先在「声音线索」页定义，再绑定到具体句子。
- 在「入口与后续」页把新场景接到任意已有调查方向，并可设置线索门槛与本场景的后续方向。
- 编辑全程为草稿，使用独立播放器，与正在调查的录音互不影响；「草稿预览」按玩家视角试听。
- 发布前自动检查：字幕越界、声音线索缺失/越界、失效时间点、线索门槛引用、场景可达入口。
  存在阻断性错误或没有可达入口时无法发布。
- 替换草稿音频会保留全部文字，超出新时长的时间点标记为「待确认」，人工确认后才重新生效。
- 取消发布不会删除保留版本：当前调查与旧存档仍可继续收听，只是图中不再出现新入口。

### 数据与可移植性

- 录音 Blob 存在本机 IndexedDB，刷新页面后仍可播放；写入采用「先落库后改状态」，
  存储配额超限时写入抛错，内存与 IndexedDB 都保留上一份可用版本。
- 创作区支持整体导出 / 导入（JSON 内嵌 base64 录音）。
- 调查存档对话框里的「案件包」会把存档与创作区一并导出；在其他设备导入时，
  场景、线索、音源与存档内部引用会自动重映射到本机新 ID。
